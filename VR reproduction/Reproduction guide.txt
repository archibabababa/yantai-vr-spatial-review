Yantai VR prototype — setup and controls

Study period: July 2025.

Files

Yantai VR - Unity source.zip contains Assets, Packages and ProjectSettings: the scene, three project FBX models, scripts, materials, controller bindings and local OpenVR dependency. SampleScene uses 5.15.fbx. Original asset names are preserved. Source file manifest.csv records the source and Windows build file sizes and hashes. Editor caches are omitted.

Yantai VR - Archived Windows build.zip contains the executable and runtime files. The CAD drawing and native Depthmap graphs are in Supplementary data/Technical sources.

Yantai VR - July 2025 study - SketchUp source.skp preserves one verified native model. After accounting for coordinate conventions, all vertices of the earlier FBX export (SHA-256 prefix fe5fb7ff33fb) match positions in this SketchUp model at 0.1 mm rounding. The active 5.15.fbx has additional mesh detail; its exact final native source has not been located. The SketchUp file is supplied unchanged, without duplicate saves or backup versions. Its study label refers to July 2025; the original model and FBX export dates precede the experiment.

Fan Huang implemented the linked-volume controls in RightControl.cs. SteamVR/OpenVR supplies tracking, input and navigation components, including vendor example assets. The standalone RightControl.cs in Technical sources has English comments; its executable code matches the archived version. See Third-party notices.txt for software credits and licences.

Open the project

1. Extract the source archive so that Assets, Packages and ProjectSettings share a root folder.
2. ProjectVersion.txt records Unity 2022.3.53f1c1. Use a separate copy for a different editor version. Let Package Manager restore dependencies; the OpenVR archive is included at the relative path specified in Packages/manifest.json.
3. Open Assets/Scenes/SampleScene.unity. RightControl on the Player rig's right-hand object has three model targets assigned. Supplied Vive bindings include GrabPinch, GrabGrip, menu and teleport.
4. Configure SteamVR and the HTC Vive headset/controllers, confirm tracking and room setup, then enter Play mode. Other devices require suitable bindings and compatibility testing.

To use the Windows build, extract it and keep VR_DemoFbx.exe, UnityPlayer.dll, MonoBleedingEdge and VR_DemoFbx_Data together in EXE. Configure SteamVR before launching the executable.

Controls

- Right trigger, held: rotate the three groups around their local vertical axes at 5 degrees per second.
- Right grip, held: move Box1 along local left and Box2/Box3 along local forward at 0.5 Unity units per second. Left grip reverses these movements. Local axes change with each group's orientation.
- Left trigger: presses 1–4 reduce every local scale component by 0.002; presses 5–8 increase them by 0.002. Press 9 resets the counter without changing the geometry.
- Right menu: presses 1–4 increase local Y scale by 0.002; presses 5–8 reduce it by 0.002. Press 9 resets the counter without changing the geometry. This is the height adjustment labelled “tilt” in the conceptual diagram.

These controls apply predefined linked transformations. Architectural constraints and spatial analysis are handled separately.

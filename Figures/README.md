## Captions

**Figure 1.** The design team revised the layout in VR. The research team assessed the revision using plan analysis and participant questionnaires.

**Figure 4.** Original and revised plans at the same scale. For each numbered landmark, the values are the medians for sampled positions within 1.2 m. Arrows run from the original to the revised value. Sightlines are horizontal. The anteroom is an approximate model location identified by the author and registered between plans using corresponding stair treads; the two stair landmarks use tread centres.

**Figure 7.** Original and adjusted visibility graph integration (a–b) and mean depth (c–d), with shared colour limits for each metric. Colour runs from blue (low) to red (high). Integration describes the graph's spatial relationships, while depth counts successive visibility links between positions.

**Figure 8.** Axial intelligibility (a–b) relates connectivity to global HH integration. Synergy (c–d) relates local integration at radius 3 to global HH integration. Each point represents an axial line with valid values for both variables: 42 in the original plan and 39 in the adjusted plan. Dashed lines show linear fits; R² is the squared Pearson correlation.

**Figure 9.** Presence ratings (Q9) by representation. Cells show the number of exact ratings at each score from 1 to 5. Student *n* is the number of exact ratings for that item; expert *n* is 15 throughout. The starred group reference means previous site experience for experts and photographs and renderings for students. Drawings and clips depict the original layout, and VR depicts the revision.

**Figure 10.** Exact score counts for the revised scheme (Q10–15) and tool (Q16–20). Student *n* varies by item; each expert row contains 15 ratings. Higher Q17 scores indicate greater physical discomfort. Interval and unscorable responses are reported separately in the data files, so the exact-score counts can differ from Table 5, which also includes confirmed 4–5 intervals.

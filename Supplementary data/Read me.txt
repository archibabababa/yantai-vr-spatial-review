Yantai museum study — data and analysis
Study period: July 2025.

Data

Anonymous participant ratings.csv is the primary analysis dataset. Fifteen students supplied 310 exact scores, 23 intervals and 12 unscorable entries; fifteen experts supplied 345 exact scores. Status is point, interval or unresolved. The SPSS archive and Expert rating sensitivity by item.csv are retained alongside this dataset. The latter is an alternate tabulation of the same experts.

Student open-response summaries.csv and Expert open-response examples.txt contain English summaries, not verbatim quotations. Reading notes preserve uncertain and crossed-out entries.

VGA Map 3.csv is the original plan; VGA Map 1.csv is the revision, both at 0.6 m grid spacing. Axial maps are zx2.csv (original) and zx1.csv (revised). Technical sources contains the CAD drawing and native graphs: sy.graph, zx2.graph and zx1.graph.

Results

The five published result CSVs correspond to Tables 3–6: Spatial metric results, Direct visibility between landmarks, Representation ratings by group, Scheme and tool ratings by group, and Paired review comparisons. Additional counts and sensitivity results are generated by the scripts below.

Table 4 uses exact-score means; Table 5 counts scores of 4 or 5, including 4–5 intervals; Table 6 uses paired exact scores. Higher Q17 scores mean greater discomfort. Student denominators vary by item; expert denominators are 15.

Sensitivity bounds allow every integer within a recorded interval, or 1–5 for unresolved entries. They are coding bounds, not confidence intervals, and need not be attainable together. Dispersion uses the 105 distinct within-group pairs; quartiles and median use the 4th, 8th and 12th ordered scores.

Figure 4 uses median horizontal sightlines and visual clustering within 1.2 m of each landmark. The anteroom is an approximate author-identified location; stairs use tread centres. Table 3(b) divides visible point pairs by all possible pairs between landmark areas. Graph links are checked against exported degrees, coordinates and distance moments at relative tolerances of 1e-5 and 5e-5. All reported pairs resolve at both tolerances.

Run

Requires Python 3.10+. Figure generation also requires NumPy and Matplotlib. From this directory, run in order:

python "Check landmark visibility.py"
python paper_ratings.py
python "Spatial measurements.py"
python "Check spatial and paired relationships.py"
python "Test sightlines and review tasks.py"
python "Compare reference conditions.py"
python "Compare presence and score spread.py"
python "Joint circulation and display ratings.py"
python "Generate analytical figures.py"

The scripts recreate the result CSVs, intermediate tables and Figures 1, 4 and 7–10, including SVG exports. Run them in a copy to retain the published outputs. See the repository README for Unity setup and study limitations, and Figures/README.md for captions.

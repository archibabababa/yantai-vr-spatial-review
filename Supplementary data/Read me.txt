Yantai museum study — data and analysis
Study period: July 2025.

Data

Anonymous participant ratings.csv contains participant, group, item, variable, score, lower, upper and status. Status is point, interval or unresolved. Fifteen students supplied 310 exact scores, 23 intervals and 12 unscorable entries. The primary record for fifteen experts contains 345 exact scores. Expert and student rating matrix.csv is the wide-format version.

Expert rating sensitivity by item.csv is an alternate tabulation of the same experts, retained for sensitivity comparisons. Student open-response summaries.csv and Expert open-response examples.txt contain English summaries, not verbatim quotations. Student reading notes preserve uncertain and crossed-out entries.

Interpretation

Table 4 uses exact-score means; Table 5 counts scores of 4 or 5, including 4–5 intervals; Table 6 uses paired exact scores. Higher Q17 scores mean greater discomfort. Student denominators vary by item; expert denominators are 15. For fifteen ordered scores, the 4th, 8th and 12th values define the quartiles and median. Dispersion uses the 105 distinct within-group pairs.

Sensitivity bounds allow every integer within each recorded interval, or 1–5 for unresolved entries. They are coding bounds, not confidence intervals; different bounds need not be attainable together.

Run

Requires Python 3.10+. Figure generation also requires NumPy and Matplotlib. From this directory, run:

python "Check landmark visibility.py"
python paper_ratings.py
python "Spatial measurements.py"
python "Check spatial and paired relationships.py"
python "Test sightlines and review tasks.py"
python "Compare reference conditions.py"
python "Compare presence and score spread.py"
python "Joint circulation and display ratings.py"
python "Generate analytical figures.py"

These commands regenerate the result CSVs and Figures 1, 4 and 7–10. Run them in a copy to retain the published outputs.

Spatial files

VGA Map 3.csv is the original plan; VGA Map 1.csv is the revision. The grid is 0.6 m. Axial maps are zx2.csv (original) and zx1.csv (revised). Technical sources contains the CAD drawing and native graphs: sy.graph, zx2.graph and zx1.graph.

Figure 4 uses median horizontal sightlines and visual clustering within 1.2 m of each landmark. The anteroom is an approximate author-identified location; stair landmarks use tread centres. Other radii and a second registration tread are retained in the result files.

Table 3(b) uses visible point pairs divided by all possible pairs between landmark areas. Direct graph links are checked against exported degrees, coordinates and distance moments at relative tolerances of 1e-5 and 5e-5. All reported Table 3(b) pairs resolve at both tolerances.
